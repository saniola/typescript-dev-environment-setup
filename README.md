# TypeScript Dev Environment Setup

A minimal TypeScript project demonstrating a basic development setup: compiling TypeScript to JavaScript and serving it with `@web/dev-server`. A button click reads a text input and logs a concatenated greeting.

## Stack

- TypeScript 5
- `@web/dev-server`

## Usage

```bash
npm install
npx tsc
npm start
```

`npm start` serves `index.html` and watches for changes.
